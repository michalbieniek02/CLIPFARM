# Settings preview

Mode: Operate. Extend the existing dark Windows workbench without changing its identity.

The user wants the left sidebar settings demonstrated on a lightly blurred photo of a generic person. The preview is a persistent right dock, so controls remain accessible on the left while the demonstration changes immediately. It is explicitly labelled as a sample frame, uses a locally bundled generated photograph, and never impersonates imported user footage.

Inherit Theme colors, 14px panel radius, native type, 24px outer margins and existing focus/disabled states. The sample uses the actual Anton caption font and size from the export module. Show live aspect ratio, letterbox/center/face crop, color correction, horizontal mirror, caption visibility, word highlighting and tempo. Show mode and duration through the resulting clip-length label; transcription precision remains a textual summary because it does not visually change an image.

First viewport: settings rail on the left, existing source/results workflow in the middle, a 248px preview dock on the right. The right dock remains visible in both Film and VOD tabs, at 1360×900 and 1100×780. Narrow center-column source content adapts without losing any transcription actions.

Signature interaction: changing sidebar controls immediately transforms the same sample frame; optional word animation uses the selected 1×/1.1× pace. Windows reduced motion shows all words without animation and disables playback.

Quality bar: all controls affect the appropriate preview state; readable example captions and sample identification; no clipped content or QML warnings at either shipped window size; original source import/export behavior remains connected.
